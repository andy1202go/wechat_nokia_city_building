# 玩法机制照搬原版，游戏名称与美术素材全部重做

用户最初的诉求是「原汁原味复刻《都市摩天楼》并上架」。这两件事互斥，必须拆开：玩法机制不受著作权法保护（广东高院《某某觉醒》案二审明确游戏玩法机制设计属于思想、系统、操作方法），可以自由复刻；美术与音乐素材受著作权法保护，不得复用原文件；游戏名称受商标法与反不正当竞争法双重保护（参照「开心消消乐」案），必须更换。

因此本项目采取：**玩法 1:1 忠实复刻 + 视觉用 Canvas 代码重绘 + 原创命名**。

## Considered Options

- **复刻原版命名与素材**（用户初选，已否决）：直接沿用「都市摩天楼」之名并复用原版素材。否决理由：与「能上线」目标互斥，且广东高院同一判决中「仅简单替换美术资源、全面照搬玩法」的行为被判赔偿 1000 万元。
- **代码绘制 + AI 生成氛围图**：视觉更有质感，但需控图片体积，且无法完全担保生成素材不撞已有版权形象。暂缓，可后续作为美术升级迭代引入。

## Consequences

- 怀旧体验不受损。怀旧感来自玩法层（吊车摆动手感、容差判定、投放节奏、黄蓝格子配色），这些全部保留；被替换的名称与素材恰好不是怀旧感的核心。
- 美术工作量变为纯代码绘制，无外部图片文件，包体几乎为零。
- 游戏名称与主色做成配置项，开发者本地可覆盖用于个人怀旧（不发布）。
- `Tower Bloxx` / `City Bloxx` / 「都市摩天楼」的权利人状态为「模糊但明确存在」——Digital Chocolate 2014 年关闭时将该 IP 之外的其余四款游戏授权给 RockYou，此作不在处置名单内，不得据此推断为无主作品。
